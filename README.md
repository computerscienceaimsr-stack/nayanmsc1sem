# Nayan Patel — Personal Portfolio

A minimal, responsive personal portfolio made with **HTML, CSS, and vanilla JavaScript**. No build tools, package installs, or frameworks required.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Optional: use VS Code with the Live Server extension for a local development server.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `nayan-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and open the Pages URL shown by GitHub.
